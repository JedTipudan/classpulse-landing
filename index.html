Installation Guide

Install on your
phone in minutes

1
⬇️

Download the APK

Tap the button below to download the latest app-release.apk from GitHub Releases.

Download APK
2
🔓

Allow Unknown Apps

Android blocks installs from outside the Play Store by default. Here's how to allow it:

Open your phone's Settings
Go to Apps → Special app access
Tap Install unknown apps
Select your browser or file manager
Toggle Allow from this source ON
💡 On some phones this prompt appears automatically when you open the APK
3
📂

Open & Install

Find the downloaded file and install it:

Pull down your notification shade
Tap the downloaded app-release.apk
Tap Install on the prompt
Tap Open when done
4
🔔

Grant Permissions

ClassPulse needs a couple of permissions to work properly:

Notifications — tap Allow when prompted
Exact Alarms (Android 12+) — go to Settings → Apps → ClassPulse → Alarms & Reminders → Allow
Camera — needed for scanning your COR
5
🔄

Staying Updated

ClassPulse checks GitHub automatically for new versions every time you open the app. When a new release is published, you'll see a popup like this:

🔄 New Update!

Version 1.2.0 is available.
Bug fixes, improved OCR accuracy, new color themes.

Later Download

Tap Download and it will open the GitHub release page where you can grab the new APK.

🍎

iOS via Expo Go

The native iOS app is in development. In the meantime, you can run ClassPulse on iPhone using Expo Go — no App Store, no Mac needed.

1
📲

Install Expo Go

Download the free Expo Go app from the App Store on your iPhone.

Get Expo Go on App Store
2
💻

Set Up on Your Computer

You need Node.js installed. Then run these commands in Terminal:

# Install Node.js from nodejs.org first, then:
npm install -g expo-cli
git clone https://github.com/jedtipudan/classpulse.git
cd classpulse-rn
npm install
npx expo start
💡 Node.js download: nodejs.org
3
📱

Scan the QR Code

After running npx expo start, a QR code appears in your terminal.

Open the Camera app on your iPhone
Point it at the QR code in your terminal
Tap the Open in Expo Go banner
ClassPulse loads on your phone!
📡 Your phone and computer must be on the same Wi-Fi network
4
🏗️

Build a Standalone IPA (Optional)

Want a real installable app without needing a computer running? Use Expo EAS Build — it builds in the cloud for free.

npm install -g eas-cli
eas login
eas build --platform ios
Create a free account at expo.dev
EAS builds the IPA on Expo's servers
Download and install via TestFlight or direct install
⚠️ An Apple Developer account ($99/yr) is required to publish to the App Store
5
🔄

iOS Updates

When using Expo Go, updates are instant — just re-scan the QR code after pulling the latest code:

git pull origin main
npx expo start

For EAS builds, run eas update to push over-the-air JS updates without rebuilding the whole app.
